
# Code Review Checklist

## 1. Correctness
- [ ] Does the code produce the correct result?
- [ ] Are boundary conditions handled correctly?

## 2. Testing
- [ ] Are unit tests included?
- [ ] Are edge cases, such as an empty roster, tested?

## 3. Readability
- [ ] Are variable and function names meaningful?
- [ ] Are complex functions explained with comments or docstrings?

## 4. Design
- [ ] Is duplicate code avoided?
- [ ] Does the code follow the existing project structure?

## 5. Risk
- [ ] Are invalid inputs handled safely?
- [ ] Could the change break existing features?
